# Sovereign Wealth • Personal Finance & Wealth Manager

Modern, editorial-grade wealth and personal finance management application built with mobile-first aesthetics, multi-currency conversion, and progressive web app (PWA) capabilities.

Designed using **Google Stitch (Google Labs)** and crafted for **Muhammad Faari Akbar**.

---

## 🌟 Key Features

1. **Dashboard & Portofolio (Home):**
   - Real-time Total Net Worth card with ambient glow and live synced status badge.
   - Privacy toggle (hide sensitive balance values with `••••••••`).
   - Multi-segment progress bar for monthly budget & categorized spending.
   - Horizontal category breakdown carousel (Food & Dining, Housing, Investments, Cloud & Subs).
   - Recent transactions list with income/expense color coding.

2. **Dinamika Arus Kas & Pertumbuhan (Analytics):**
   - Dual-line smooth SVG area chart comparing Inflow (Income) vs Outflow (Expenses).
   - Dynamic net retained savings calculation and savings rate indicator.
   - AI Capital Advisor card delivering personalized financial insights.
   - Cutout donut chart visualizing budget composition across 5 sectors.

3. **Kartu & Rekening Bank (Cards & Wallets):**
   - Interactive World Elite Platinum Card preview with metallic gradients and chip styling.
   - Real-time **Freeze / Unfreeze Card** toggle with visual lock state.
   - Monthly spending cap limit tracker.
   - Linked bank account integrations (BCA Priority Checking, Bank Mandiri Tabungan).

4. **Target Masa Depan (Goals & Vaults):**
   - Goal progress trackers (Emergency Fund 100%, Japan Autumn Trip 64%, Startup Angel Fund 51%).
   - Automated smart rules (Round-up spare change, Payday auto-split 20%).

5. **Kirim & Transfer Uang (Send Flow):**
   - Frictionless transfer flow with favorite recipient avatar chips.
   - Quick increment amount pills (+100rb, +500rb, +1 Juta, Max).
   - Instant transfer confirmation.

6. **Global Multi-Currency Engine (8 Mata Uang):**
   - Default: **IDR (Rp)**
   - Supported conversions: **USD ($)**, **EUR (€)**, **GBP (£)**, **JPY (¥)**, **KRW (₩)**, **CNY (¥)**, **SGD (S$)**.
   - Real-time conversion across all 5 screens with proper locale formatting.

7. **PWA & Mobile Install Ready (PWABuilder):**
   - Fully compliant `manifest.json` and standalone display mode.
   - Custom 192x192 & 512x512 app icons.
   - Offline-capable Service Worker (`sw.js`).
   - One-click installable as an Android APK or iOS Home Screen App.

---

## 🚀 Tech Stack

- **HTML5 & CSS3** (Mobile-first standalone shell)
- **Tailwind CSS** (via CDN with bespoke Material 3 / Sovereign design tokens)
- **Vanilla Modern JavaScript** (SPA Tab router, Currency engine, State management)
- **Google Fonts** (Inter & Material Symbols Outlined)
- **PWA Service Worker** (Cache-first offline support)

---

## 📲 How to Run Locally

Simply double-click `index.html` or open it in any modern browser:
```bash
Start-Process index.html
```
